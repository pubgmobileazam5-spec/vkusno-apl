# Вкусно — приложение рецептов

Готовый адаптивный интерфейс по мотивам присланного скриншота. Внутри есть:
- нижняя панель «Создать / Меню / Подбор / Покупки»;
- горизонтальные подборки и категории со свайпом;
- карточки рецептов, открытие подробностей, ингредиенты и шаги;
- избранное и локальный список покупок;
- поиск по названию, описанию, категории и ингредиентам;
- добавление собственных рецептов;
- сохранение данных на устройстве через localStorage.

## Быстрый просмотр
Открой `index.html` в браузере или запусти локальный сервер в этой папке.

## Сборка APK через Capacitor
Нужны Node.js LTS, Android Studio и Android SDK.

```bash
npm install
mkdir -p www
cp index.html styles.css app.js manifest.webmanifest www/
cp -r assets www/
npx cap add android
npx cap sync android
npx cap open android
```

В Android Studio дождись Gradle Sync, затем выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

Если папка `android` уже создана, после изменений файлов повторяй:
```bash
cp index.html styles.css app.js manifest.webmanifest www/
cp -r assets www/
npx cap sync android
```

## Важно
Это автономный первый релиз без сервера и аккаунтов: рецепты, избранное и покупки хранятся локально на устройстве. Изображения в демо-каталоге загружаются из Unsplash, поэтому для них нужен интернет. Перед публикацией в Google Play стоит добавить собственные изображения, политику конфиденциальности и проверить права на контент.
